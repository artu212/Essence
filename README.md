
# Essence

**More than a look**

Sistema web de gerenciamento de agendamentos para barbearias, salões de beleza e outros estabelecimentos de serviços.

## Objetivo

Facilitar o agendamento de serviços, permitindo que clientes encontrem estabelecimentos, escolham profissionais e reservem horários de maneira simples.

## Funcionalidades previstas

- Pesquisa de estabelecimentos.
- Consulta de serviços e profissionais.
- Agendamento sem necessidade de cadastro.
- Verificação de disponibilidade de horários.
- Gerenciamento de agendamentos.
- Painel administrativo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
